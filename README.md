# Tecnofile
🦾 Prótesis de Brazo Robótico Controlado por App Móvil
Introducción
Este proyecto consiste en el desarrollo de una prótesis de brazo robótico funcional, diseñada para ser controlada de manera remota a través de una aplicación móvil. La idea principal es ofrecer una solución accesible e intuitiva para personas con amputaciones, permitiendo controlar los movimientos del brazo artificial desde un smartphone, mediante una interfaz sencilla y amigable.

La prótesis está equipada con motores y sensores que permiten realizar movimientos básicos como abrir y cerrar la mano, rotar la muñeca o flexionar el codo. Todo el sistema se comunica de forma inalámbrica con una app móvil desarrollada específicamente para este propósito, lo que permite controlar el brazo en tiempo real.

El proyecto combina electrónica, robótica, diseño 3D e ingeniería de software, y está enfocado en ser de código abierto, permitiendo que cualquier persona interesada pueda estudiarlo, mejorarlo o adaptarlo a nuevas necesidades.
